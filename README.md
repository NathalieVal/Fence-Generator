# Fence-Generator
A procedural fence generator for Maya 2026

This project is supposed to be a Python-based tool that can be used to generate customizable fence assets through the use of NURBS curves. The goal is to speed up the process of creating fences for environments while still allowing the user to have full creative liberty.

BASIC GOALS:
- Ability for fence to be generated based on NURBS curve (pretty important if I do say so myself)
- Customization
  | Adjustable spacing and dimensions of posts & rails
  | Adjustable chain thickness(?)
- Two Fence Types:
  | Post & Rail
  | Chain Link

^^ These make up the core requirements of the tool. Once these are functioning, then additional elements will be added.
